Employee Attrition Prediction using Machine Learning
📌 Project Overview
Employee attrition refers to employees leaving an organization.
This project aims to analyze employee data and predict whether an employee is likely to leave the company using Machine Learning techniques.
The goal is to help the HR department take proactive actions to reduce attrition.

📊 Dataset
Dataset Name: IBM HR Analytics Employee Attrition Dataset
Source: Kaggle
File Format: CSV
Target Variable: Attrition (Yes / No)
Dataset Link:
https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset

🧩 Technologies Used
Python
Pandas
Matplotlib
Seaborn
Scikit-learn
Jupyter Notebook
🔍 Steps Performed
Data Loading and Understanding
Exploratory Data Analysis (EDA)
Data Preprocessing
Converting target variable to binary
Train-test split
Feature scaling
Model Building
Model Evaluation
🤖 Machine Learning Model
Model Used: Random Forest
📈 Evaluation Metrics
Accuracy Score
Confusion Matrix
Classification Report
📌 Results
The model successfully predicts employee attrition.
Accuracy achieved is approximately 85% (may vary slightly).
Employees with low job satisfaction and lower income show higher attrition.
